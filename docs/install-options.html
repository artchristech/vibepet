One-liner

Downloads the right build for your Mac, installs it to /Applications, and skips the "unidentified developer" prompt.

curl -fsSL vibepet.net/install | sh

From source

It's about 1,000 lines of Electron. Fork it, give your pet a new trick.

git clone github.com/artchristech/vibepet && cd vibepet && npm i && npm start

Re-run the one-liner any time to update. To enable chat, right-click your pet → Set Anthropic API key, or launch with ANTHROPIC_API_KEY set.
